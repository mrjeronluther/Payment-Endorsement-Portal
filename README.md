## Project Overview
The Payment Endorsement Portal is a comprehensive web application designed to streamline the process of endorsing payments and managing requests for proposals (RFPs). The portal consists of a backend powered by Google Apps Script and a frontend built with Vue.js, providing an intuitive user interface for users to interact with the application.

## Project Structure
The project is organized into two main directories:
- **backend**: Contains the Google Apps Script code and configuration for handling backend logic.
- **frontend**: Contains the Vue.js application code that manages the user interface.

## Functionality
- **User Authentication**: Users can securely log in to the portal.
- **RFP Management**: Create, view, and manage RFPs with ease.
- **Payment Endorsements**: Fast-track payment endorsements through the portal.

## Key Features
- User-friendly interface built with Vue.js
- Secure authentication with industry-standard methods
- Dynamic RFP generation and submission workflows
- Integration with Google Apps Script for backend processing

## Components
- **Vue.js Components**: Reusable components (e.g., forms, buttons) for building the UI.
- **Google Apps Script Libraries**: Scripts that handle backend functionality and integration with Google services.
